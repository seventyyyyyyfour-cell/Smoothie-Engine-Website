How to use Smoothie Engine

Everything you need to move around, save your work, and bring objects to life with visual scripts.

Basic usage Scripting

Basic usage

Move the camera, pick objects, and keep your projects safe.

Name your project in the top left corner before you save it.

Scroll wheel
Zoom in and out.
RMB or Scroll wheel
Click and hold, then drag to move the camera.
LMB
Move and select objects.
Ctrl + S
Save your project. You can also press Save at the top middle.
Ctrl + O
Load a project. You can also press Load at the top middle, then pick your project from the list at the bottom.

Scripting

Add behavior to any object with the visual script editor.

Add a script

  1. Select the object.
  2. Click Add Modifier.
  3. Choose Visual Script.

Work with nodes

Top buttons
Click the button for the node you want to add it.
RMB + drag
Drag from one node to another to connect them.
LMB + drag
Click and hold a node, then drag it where you want it.
Click, then Delete
Select a node and press Delete to remove it.

Create variables

Click empty space to deselect all nodes, then use the right panel in the VS tab.
